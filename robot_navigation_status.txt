CONVENTIONS  (Grok's, written into the Label / Context words)
  quaternion = [w, x, y, z], real part first; axes right-handed, x forward, y left, z up; angles in radians; a vector is turned by q v q^-1;
  roll about x, then pitch about y, then yaw about z (q = yaw * pitch * roll).  Heading: 0 points east, positive turns toward north.
  g = 9.81 m/s^2, Earth radius 6371000 m, GM = 3.986004418e14, c = 299792458.  Latitudes and longitudes are radians.  A position is a list.
  A chained box carries ONE number, so a list answer is one row (or one row per component).

HOW TO ADD A BATCH  (what worked; the scripts were throw-away files in the scratchpad)
  1. Write the Python operator files operators_one_operator_per_file/<group>/<name>/<name>.py (compute() with the plan's messages), the row files
     operator_row_math/<group>/<name>/<name>.py (copy a similar one: INPUTS, KINDS, CALC), INDEX.md lines, and one spec line per operator in
     operator_keys/operator_row_specs.txt (boxes in the order of compute()'s INPUTS is not required: boxes are matched by name).
  3. Multi-row menu operators: operator_row_math/multirow_specs.py , with
     {"chain": k} for boxes that read an earlier row and links for boxes that copy another box.
  4. Run: python operator_keys/make_operator_row_files.py, make_operator_keys.py;
     draw pictures with python operator_keys/make_navier_stokes_pictures.py <keys> (only on this machine: it needs Cambria).
  5. Update the counts (README.md, TESTING_GUIDE.md, operator_keys/README.md, tests/test_operators.py, tests/test_operator_pictures.py).  Careful: a blanket sed of the old count also hits legitimate numbers
     (2^3^2 = 512 in test_operators.py once became 523).
  6. Tests: python -m unittest tests.test_operators tests.test_operator_pictures.
